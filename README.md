# Dreamento Dev Path — Lab Notebooks

Colab notebooks for the [Dreamento Dev Path](https://course.emolio.com/course/dreamento-dev-path) course — a technical companion to [Lucid Dreams](https://course.emolio.com/course/lucid-dreams) for programmers and vocational (MBO/VET) students building toward real contributions to [Dreamento](https://github.com/dreamento/dreamento), the open-source EEG sleep/lucid-dream engineering toolbox.

Each notebook opens directly in Google Colab — no install, no download, free GPU/CPU included.

| 2 — Sleep Architecture & AASM Scoring | `notebooks/ch2_sleep_architecture.ipynb` | [Open in Colab](https://colab.research.google.com/github/emolionl/dreamento-dev-path-labs/blob/main/notebooks/ch2_sleep_architecture.ipynb) |
| 3 — The Frequency-Domain View | `notebooks/ch3_frequency_domain.ipynb` | [Open in Colab](https://colab.research.google.com/github/emolionl/dreamento-dev-path-labs/blob/main/notebooks/ch3_frequency_domain.ipynb) |

All labs use free, public data (PhysioNet's Sleep-EDF, fetched automatically via MNE-Python) — no EEG hardware required to start.
